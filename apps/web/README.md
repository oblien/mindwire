# @mindwire/web

The marketing site and documentation for **mindwire**, built with Next.js (App Router) and
Tailwind, exported as a fully static site (`output: "export"`).

## Develop

From this directory (or via `bun --filter='@mindwire/web' run <script>` at the repo root):

```bash
bun install          # at the repo root — installs all workspaces
bun run dev          # build docs, then next dev  → http://localhost:3000
bun run build        # build docs, then next build → static export in out/
bun run serve        # serve the built out/ locally on :4327
bun run check        # tsc --noEmit
```

`dev` and `build` first run `scripts/build-docs.mjs`, so the generated docs are always in sync.

## Docs pipeline

Documentation lives as markdown in [`content/docs/`](./content/docs). At build time,
[`scripts/build-docs.mjs`](./scripts/build-docs.mjs):

- renders each page in-site at `/docs/<slug>`, and
- emits the raw markdown to `public/docs/<slug>.md` (so every page is also available as raw
  markdown at `/docs/<slug>.md`), plus an [`llms.txt`](https://llmstxt.org) index at
  `public/llms.txt`.

Both `public/docs/` and `public/llms.txt` are generated artifacts (gitignored). The final static
export in `out/` is likewise generated by `next build` — never hand-edit it.

### Authoring a docs page

Add a `.md` file to `content/docs/` with this frontmatter contract:

```markdown
---
title: Page Title
description: One-line summary (used for <meta> and the llms.txt index).
group: Guide          # sidebar section
order: 2              # sort order within the group
---

Body in GitHub-flavored markdown…
```

The sidebar is built from `group` + `order`; a `Reference` group with external links is added by
[`app/docs/layout.tsx`](./app/docs/layout.tsx).

## Layout

```
apps/web/
├── app/              routes: / · /pricing · /changelog · /sandboxing · /docs/[slug]
├── components/       Nav, Footer, DocView, diagrams, theme toggle, …
├── content/docs/     markdown source (the only place you edit docs)
├── lib/docs.ts       frontmatter parser + marked renderer
├── scripts/build-docs.mjs   raw-markdown + llms.txt generator
├── public/           static assets (+ generated docs/, llms.txt)
└── out/              static export (generated by `build`)
```
